# 节点管线

`YokoWave.Pipelines` 是不依赖 Avalonia / Nodify 的纯 .NET 项目。波形、滑动、声控、禁锢、运动、睡眠剥夺、泵、原生程序和网络服务端均为普通图模板，只使用 `PipelineSession` 一套执行流程。画布操作说明位于应用内「帮助」。

## 图与注册

`PipelineDocument` 保存实例 ID、名称、节点定义、连线、布局、定时、暴露端口和设备分组。`NodeDefinition` 保存稳定类型键与配置 JSON，端口以节点 ID 和稳定端口键引用；不序列化控件模型或运行资源。

`NodeTypeRegistry` 以类型键查找注册。`NodeRegistration<T>` 定义配置读取、验证、端口、处理器工厂，以及可选的设备绑定、资源参与者、动态端口和波形引用。`ISignalProcessor.Evaluate` 同步执行，不访问设备、文件、音频或网络。

| 类别 | 当前行为 |
| --- | --- |
| 输入 | 常量、带标记的模拟数值、触控、音频特征、设备传感器、统一控制帧 |
| 波形 | 单波形／播放列表、相位、重复／单次／顺序／随机、触发重启与完成信号 |
| 数值 | 增益、限幅、范围映射、基准偏差、频率／脉宽映射、混合、选择、阈值、平滑、强度进度 |
| 活动与时间 | 运动计数和目标、固定／随机等待及输出周期、活动重置、双泵独立计时 |
| 输出 | 独立通道、泵、原生程序、统一帧路由、设备命令 |
| 组合与网络 | 嵌入子图、GATT 服务端、control 服务端、DG-LAB V4 被控设备／传感器共享及中继 |

## 数值契约

`NumericSignal` 含一个标量或四个 25 ms 样本、`ValidUntil`、`Simulated` 和输入序号。组合取较早有效期、合并模拟来源并保留序号语义，不把变换后的输入当作全新采样。意图端口只承载原生程序和统一帧的结构化元数据。

单位和范围属于目标 `NumericParameterSpec`，不是独立的信号类型。常用范围如下：

| 参数 | 合法数值 |
| --- | --- |
| 强度、相对脉宽、节点上限 | 0–1 |
| 频率 | 1–100 Hz |
| 泵方向 | 整数 0 停止、1 正转、2 反转 |
| 水泵开关 | 整数 0 / 1 |
| 两路泵时长 | 整数 0–65535 秒，0 为持续 |

未连接输入使用端口默认值；已连接但缺失、过期、非有限或越界的输入归零等待，不回退到非零默认值。模拟来源不能驱动真实输出或命令。

波形源只暴露当前资产定义的 `levelA` / `levelB` / `levelC`，频率与脉宽共用。波形切换后缺失通道归零，原路由保留并暂时隐藏；恢复定义后重新出现。无独立通道的资产只提供 A，可连接多个输出。详见[波形](waveforms.md)。

## 编译与模板展开

编译器创建独立快照，验证版本、ID、注册配置、连线方向、端口种类、单位范围、循环、输出冲突、设备能力与资源要求，再按拓扑排列处理器。目标在线、占用等动态条件在控制器申请时复核。

用户模板通过 `ExposedPort` 暴露输入／输出。实例嵌入独立子图快照，编译时重映射内部 ID、设备引用和端口，最终展开为一个 DAG 和一次资源申请。外部输入覆盖模板内部来源；没有外部连线时保留内部连线，仍未连接时使用最外层模板默认值。编译器校验各层引用、方向、类型与默认值。

嵌套最多 16 层，展开后最多 1000 个节点、8000 条连线。`PipelineTemplates` 生成本地模板，`RemotePipelineNodes` 注册网络模板；模板键不参与运行期分派。`PipelineBuilder` 的默认上限只用于创建输出节点，不构成图级运行上限。

## 求值与输出

`PipelineRuntime` 每帧同步求值，处理器独享状态。`IInteractiveProcessor` 接收数值、波形、滑动、增强、校准、泵及命令更新；`ISuspendableProcessor` 清除暂停时不应保留的输入状态。

`DeviceOutputCoordinator` 先按输出／控制节点独立限幅，再合并同一设备的通道。`PipelineOutputDispatcher` 负责命令顺序、独立设备并行、定时泵指令去重、已发送帧和峰值；设备控制器再应用硬件设置及能力范围。泵没有可缩放的流量百分比：节点上限为 0 则停泵，非零不按比例缩放流量。

原生程序覆盖电击固定预设、V2 缓冲序列、马达固定程序及郊狼 V2 原始 X/Y/Z。马达固定程序只有开关能力，非零通道和原生节点上限必须为 100%；可调幅度使用普通波形。

## 会话生命周期

1. 编译并确认配置，等待待保存的硬件设置。
2. 原子申请节点实际引用的设备；创建新处理器、输出派发器和资源参与者。
3. 启动输入／网络资源，后台按单调活动时间捕获、求值、提交；节拍约 100 ms，可携带四个 25 ms 预取样本。
4. 暂停归零并保留占用，冻结活动时间；继续前恢复资源。当前桌面工具栏只提供开始／停止，暂停／继续供远程控制与会话 API 使用。
5. 停止取消后续帧并等待在途写入，先撤销网络输出，再归零、停流、释放输入，确认后释放占用。失败保留原始及清理错误，允许停止重试。

停止可取消输入启动；失败回滚成功后不保留输入、帧或倒计时。单次完成节点均完成后结束会话，较早完成的源先归零。定时使用后台时钟，不依赖页面可见性或 UI Tick。

分组归属与设备引用独立：加入／移出设备不改变节点或布局，可填入兼容空引用。未引用成员不参与 I/O。运行期锁定拓扑、归属和绑定；支持的实时参数及每个节点的上限仍可调整。停止、全部停止和断连共用生命周期入口。

## 编辑投影与验证

App 的编辑器维护节点／端口 VM、选择、撤销／重做和图片段。参数修改更新现有节点与表单；历史恢复和粘贴才重建投影。通道下拉框来自设备实际通道掩码，硬件配置位于设备页，不复制到各输出节点。

已发送强度条来自成功发送、经过节点和硬件上限的指令，不是物理测量。正常停止归零，无法确认时显示未知；输入节点和泵不显示百分比条。

测试覆盖编译、有效期与来源传播、模板隔离、输入启动与回滚、限幅和停止屏障、子图及 Headless 编辑。大图检查断言 200 个节点和 500 条连线的实际控件及绑定，不将单次耗时当作性能保证。参见[测试](testing.md)、[输入](inputs.md)与[存储](storage.md)。
