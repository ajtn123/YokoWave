# YokoWave 节点玩法

所有玩法均由节点图执行。波形、滑动、声控、禁锢、运动、固定／随机／活动重置睡眠剥夺、泵和原生程序是普通图模板，使用相同编译器、调度器、设备独占和停止流程。WebSocket GATT／control 服务端也是图中的资源节点。

## 使用

1. 在设备页扫描、连接与断开本地、模拟或远程设备，WebSocket 来源也在设备页管理。节点玩法页只显示已连接设备，按实例分组并单列未分配设备；卡片仅用于查看、加入或移出。加入或移出设备不增删节点、连线或布局；加入时可自动填入兼容的空设备引用。断连会隐藏卡片并保留归属与引用，重连后回到原组。
2. 在参数面板将 `$device`、`$sensor` 等引用替换为设备。一个图可以使用多个输出与输入设备。分组归属与节点引用分别保存；空闲设备也只归属一个实例，须先从原分组移出才能改派。启动时仅原子申请节点实际引用的资源；未被节点引用的成员不会参与 I/O，其断连也不会结束会话。
3. 右键画布选择「添加节点」，节点出现在点击位置；右键拖动仍用于平移。也可展开可搜索节点库。拖动端口连线。数值表示强度比例 0..1、频率 Hz、相对脉宽 0..1；单位与合法范围由目标端口定义。未连接端口使用其默认值；已连接但缺失、过期、非有限或越界的参数归零等待。
4. 通道输出、泵输出和原生程序接收数值输入。一个设备的 A/B/C 通道分别限幅，再合并一次提交。泵方向为整数 0（停）、1（正转）、2（反转），水泵为 0/1，时长为 0..65535 整数秒；0 为持续，协议没有流量百分比。泵输出节点上限为 0 会停泵，非零比例不缩放流量。
5. 顶部同一按钮切换开始与停止。开始后可实时修改数值、各输出节点上限、波形、滑动参数、泵参数，以及增强／校准／命令触发。拓扑、设备归属、绑定和其他配置锁定。停止后释放已确认归零的资源。WebSocket 高层控制仍支持暂停与继续，暂停归零并保留占用，不计算暂停时间。
6. 定时开关、秒级滑块和时间读数位于同一行；运行时隐藏开关与滑块，只显示轨道内的收缩进度条及独立倒计时。关闭定时时只显示开关，保留所选时长且没有隐含期限。最大时长在设置中配置。
7. 右键画布提供适应画布与节点编辑操作；未选择节点时禁用删除。停止玩法后，Alt＋左键点连线移除单条，点端口断开该端口全部连线；在同一对已连接端口间再次拖线也可移除该连线，Ctrl+Z 可恢复。支持选择、拖动、缩放、复制／粘贴、删除、撤销／重做；快捷键为 Ctrl+C/V/Z/Y、Delete。节点库和参数面板可收起。
8. 右键玩法列表可复制、保存、删除玩法，或另存为模板。右键某个玩法时操作该玩法；删除模板针对上方下拉框当前选中的用户模板。另存为模板时可输入名称，留空使用玩法名称。

设备页提供自动连接开关，默认关闭。手动连接成功的设备标识保存在全局 `settings.json`；开启后在启动扫描及掉线后重试，失败退避为 5–60 秒。手动断开会移除该设备的自动连接记录，扫描、手动连接和切换来源串行执行，关闭应用时取消并等待连接任务结束。重连先结束原会话，再以零输出建立连接，不自动恢复玩法。远程设备需先在设备页接入其 WebSocket 来源，凭据不随自动连接设置保存。

## 节点分类

| 类别 | 节点 |
| --- | --- |
| 输入 | 常量、明确标识的模拟数值、触控、音频、设备传感器、控制帧 |
| 波形 | 单波形、独立播放列表；重复、单次、顺序、随机；独立源通道端口与相位配置 |
| 数值处理 | 增益、限幅、范围映射、基准偏差、参数映射、混合、选择、阈值、平滑、强度进度 |
| 时间与活动 | 运动计数／目标、固定或随机等待／输出周期、双泵独立计时 |
| 输出与命令 | 单通道、双泵、原生程序、设备路由、带启动／数值触发的设备命令 |
| 组合与网络 | 嵌入子图、WebSocket GATT 服务端、WebSocket control 服务端 |

波形与播放列表节点仅显示当前波形已定义的 `levelA`／`levelB`／`levelC` 数值输出，频率与相对脉宽共用。无独立通道数据的波形只显示 A，可将同一端口接到多个设备通道。运行中切换或顺序播放到缺少某个通道的波形时，该通道归零，端口与对应连线暂时隐藏；路由仍保存在图中，通道重新出现后恢复。设备插口仍由输出节点的通道下拉框选择。

电刺激／震动通道、原生程序与路由输出节点显示已发送强度条，不显示百分比文字。读数来自最近成功发送且经过节点和硬件上限的指令；多通道节点按设备能力分别显示。正常停止后归零，无法确认输出的故障显示不确定状态。泵与输入节点不显示百分比强度条。

音频只在运行或校准期间开启；核心处理器消费特征帧，平台层负责媒体播放、麦克风和系统声音。静音、无数据和媒体结束归零等待，实际输入错误停止图。模拟来源与有效期经过数值处理后保留；模拟数据不能驱动真实输出或命令。

原生程序编辑器提供电击预设、频率／脉宽缓冲序列、马达预设和郊狼 V2 X/Y/Z 脉冲。每个输出／控制节点拥有独立上限，可实时调整；数值限幅输入作为额外约束。同一设备的不同通道不会互相压低上限。硬件选项在设备页右侧详情卡片直接显示，按型号提供温柔模式、辅助马达、硬件通道上限、相对强度和 DG 平衡；修改后串行更新本地设备设置并保存到 settings.json，保存失败会报告错误；启动与关闭前等待待保存设置完成，玩法输出时统一应用；建连、设置更新、暂停和停止保持输出关闭。运行和暂停期间不可编辑，辅助马达与运动流不能并用。输出通道下拉框只列出当前设备实际提供的通道。

节点参数、命令节点配置、播放列表与相位、触发重启、播放结束停止、音频噪声底线和原生缓冲序列均通过对应控件编辑，修改后直接保留，无需应用按钮。编辑不重建节点或表单，支持撤销／重做；暂时不满足参数间约束时显示诊断并禁止启动，修正后恢复。缓冲序列与采样波形支持逐行修改、增删及排序；界面不提供 JSON 配置入口。JSON 仅用于波形数据导入导出和内部文件存储。

## 用户模板与子图

勾选节点输入／输出端口，将当前图保存为模板。新实例嵌入独立图快照，可保留为子图或展开编辑；设备引用可以整体替换。未连接的暴露数值输入使用模板定义的默认值。编译时递归展开为同一 DAG 和一次资源申请，各实例具有不同内部 ID、处理器与状态。最大嵌套深度 16，展开后最多 1000 节点、8000 连线。

## 运行与存储

`YokoWave.Pipelines` 是纯 .NET 项目，不依赖 Avalonia 或 Nodify。注册表描述配置、端口、验证、资源和处理器工厂；编译器生成配置／波形快照并检查连线、循环、重复写入、资源冲突及设备能力。同步处理器不执行 I/O。资源参与者管理输入和网络，`PipelineSession` 在后台约每 100 ms 求值和提交，保留四个间隔 25 ms 的样本。

停止取消后续输入与帧，等待在途写入，撤销网络控制，归零、停止流、释放输入，确认后释放设备。失败保留原始和清理错误，未确认的设备保持占用，允许停止重试。界面关闭、Escape、全部停止和断连使用同一流程。每次完成仅生成一条会话摘要；GATT 透传的输出峰值标为未知。

`pipelines.json` 保存实例、连线、配置、设备分组归属、节点设备引用、定时和布局；`pipeline-presets.json` 保存用户模板。均为紧凑 JSON 和临时文件替换，不包含第三方控件、运行时、句柄或凭据。凭据仅保留在内存。打开图不会自动连接设备或开始输出；无法读取的文件不会被自动覆盖。

## 验证范围

测试覆盖模板行为、音频等待与生命周期、触控录制、活动周期、原生程序、所有默认波形的设备转换、设备独占与停止重试、子图、两种远程链路，以及 Headless 鼠标拖线、参数绑定、语言、主题和持久化。截图及 200 节点／500 连线的初次创建和渲染测量输出至 `artifacts/screenshots/`，不代表原生窗口的持续拖动帧率。

真实 BLE 后端在 Windows；其他桌面平台可使用模拟与 WebSocket 设备。管线的新增硬件输出路径尚未进行非零实机验证。
