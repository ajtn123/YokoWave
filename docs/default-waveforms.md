# 统一波形格式

默认波形、自定义波形、滑动录制和 JSON 导入导出都使用 `FormatVersion: 1`，不再保存厂商波形家族或协议编码。设备协议转换只在播放时执行，不修改波形和玩法预设。

## 数据格式

顶层仍为波形数组。每条波形包含 `Id`、`Name`、`FormatVersion`、`Shape`、`PeriodSeconds`、`Frequency`，以及自定义插值点 `Points` 或采样序列 `Samples`。`Frequency` 是生成曲线的频率，单位 Hz。采样序列的帧间隔为 `PeriodSeconds / Samples.Length`，每帧保持到下一帧。

| 采样字段 | 范围 | 含义 |
| --- | --- | --- |
| `Level` | 0–1 | 相对于玩法基础强度的包络 |
| `FrequencyHz` | 1–100 Hz | 脉冲频率 |
| `PulseWidth` | 0–1 | 相对脉宽／波形幅度，不代表跨设备校准的物理量 |
| `Channels` | 可省略，1–3 个 −1–1 数值 | 各逻辑通道的有符号倍率；省略表示所有通道倍率为 1，数组中未提供的通道为 0 |

`Level`、`FrequencyHz`、`PulseWidth` 必须显式存在于采样 JSON 中。未知版本或缺少必要字段直接拒绝，不把旧协议字段默认为零。所有数值必须有限，单条最多 256 帧或插值点，周期为 0.2–60 秒。

```json
[
  {
    "FormatVersion": 1,
    "Id": "edca5dc0-2a7b-491c-a0a6-3bd6913b35ca",
    "Name": "Custom",
    "Shape": "Sampled",
    "PeriodSeconds": 0.2,
    "Frequency": 20,
    "Samples": [
      { "Level": 1, "FrequencyHz": 20, "PulseWidth": 0.4, "Channels": [1, 0.5, -0.5] },
      { "Level": 0.5, "FrequencyHz": 40, "PulseWidth": 0.8, "Channels": [1, 1, 0] }
    ]
  }
]
```

生成曲线也渲染成同一种采样：曲线值进入 `Level`，`PulseWidth` 为 1。预览幅度为强度包络 × 相对脉宽 × 最大通道倍率绝对值，不把预览值再次乘进强度。波形只显示名称、参数和预览。

## 默认数据及转换来源

两个嵌入资源与普通导入导出使用完全相同的波形结构，可直接通过普通波形导入器读取。额外的 `NameKey` 用于本地化，`SourceId` 仅用于来源核对，不参与设备编码。稳定 ID、采样数和时间间隔保持不变。

| 来源 | 数量／采样 | 转换 |
| --- | --- | --- |
| 原应用电击系统波形 | 12 条 | `Level=1`，频率 PL 按 Hz 保存，TL 除以 100 作为相对脉宽；协议无效的 0 Hz 归为最低 1 Hz，与原发送路径一致 |
| 原应用电机 f1 系统波形 | 10 条 | `Level=1`、`PulseWidth=1`，三路有符号值除以 20 保存为 `Channels`；源数据没有脉冲频率，使用默认 20 Hz |
| 郊狼公开呼吸／潮汐示例 | 2 条，48／92 个采样 | 周期毫秒转换为 `1000 / period` Hz；幅度除以 100，`Level=1`；每组 100 ms 展开为四个 25 ms 采样 |

原系统数据共 22 条（1,379 帧），未收录用户分享波形及 f2 分类波形。郊狼两条示例来自厂商的 [V3 波形示例](https://github.com/dungeonlab-open/dglab-bluetooth-protocol/blob/main/coyote/v3/example_cn.md)，不代表其全部系统波形。总计 24 条、1,519 帧，均不可删除或覆盖，可复制后编辑。

YOKONEX 频率和脉冲时间单位依据厂商 [V1／V2 蓝牙文档](https://github.com/YCY-YOKONEX/YCY-YOKONEX-OpenSource/tree/main/Bluetooth)。波形数据内置，无需登录或联网，应用不读取本地参考账号凭据。

## 播放时转换

- YOKONEX 电击器：基础强度 × `Level`，Hz 取整到协议频率；相对脉宽 × 通道倍率绝对值映射到 0–100 µs。
- 郊狼 V2：Hz 转换为周期并编码 X／Y，相对脉宽映射为推荐的 Z≤20；单次读取当前采样。
- 郊狼 V3：每包四个 25 ms 采样，频率转换为压缩周期，幅度映射到 0–100。四帧包络使用包内峰值设置强度，再对各帧幅度归一，避免重复乘包络或超过玩法上限。
- YOKONEX 震动器／负鼠：相对脉宽与通道倍率作为震动幅度，忽略脉冲频率。负鼠同样保留每包四个幅度采样。
- 当前输出协议只支持非负幅度，因此有符号通道取绝对值；符号仍完整保存在文件中，设备没有的通道忽略。方向和电击频率效果无法由单向震动设备复现。
- 所有转换继续受玩法强度、上限、暂停和停止约束。单次播放及定时结束之后的四帧预取位置补零。旧设备的时间分辨率和参数量化更粗，跨设备播放不代表物理效果等价。
- 泵继续使用方向／开关控制；爪印、灵猫是输入设备，不作为波形播放目标。

## 存储

`presets.json` 仅保存统一格式的自定义波形，玩法只引用波形 ID；不保存按设备转换的副本。配置和会话存储继续使用紧凑 JSON，导出文件可以缩进便于编辑。

工作区使用 Schema 6。开发阶段不迁移旧版 Schema，格式不匹配时只重置已知应用数据文件，保留同目录其他文件。导入导出统一使用当前格式。参考 APK、原始 PDF、提取源码、研究脚本和账号凭据始终留在 Git 忽略的本地目录。
