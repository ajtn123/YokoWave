# 默认波形

`src/YokoWave.Core/Data/default-waveforms.json` 保存规范化的系统波形数据，作为嵌入资源随应用提供。2026-11-06 经用户授权登录并核对两个参考 APK 所使用的列表接口，去重得到 22 个系统波形，共 1,379 帧。这里只包含接口标为系统预设的数据，不收录用户分享波形。

| 类别 | 数量 | 名称 |
| --- | ---: | --- |
| 电击 | 12 | 潮汐、连击、压缩、快速按捏、按捏渐强、心跳节奏、节奏步伐、呼吸、颗粒摩擦、渐变弹跳、波浪涟漪、变速敲击 |
| 电机 f1 | 10 | 逆时针旋、真空口吸、正反、出其不意、火力全开、蓄力反攻、三重节奏、心跳共振、寸止、吸 |

电机分类接口列出 `f1` 和 `f2`；显式查询 `f2` 未返回系统波形。其他设备波形类别也返回空列表。上述数量代表核对时服务端提供的全部系统数据，不保证未来服务端不会更新。

## 数据字段

- `id`：应用内稳定 GUID；`sourceId`：原数据记录 ID，供维护去重。
- `name` / `nameKey`：原名称及 JSON 本地化键。界面通过键显示中英文名称。
- `family` / `deviceCode`：波形类型与原设备分类。
- `sampleIntervalSeconds`：原编辑器使用的 0.1 秒帧间隔；完整周期为帧数乘以该间隔。
- `frames[].level`：模拟器的归一化幅度。电击使用原脉宽值除以 100，电机使用三个电机值的最大绝对值除以 20。
- `frequencyCode` / `pulseWidthCode`：原电击采样的 PL / TL 值，完整保留，范围 0–100。这是原始编码，不应直接解释为 Hz。
- `motors`：原电机采样的三个有符号值，范围 −20 至 20；方向与各路值均保留。

`Sampled` 波形每帧保持到下一帧，周期重复。预览与模拟输出使用 `level`；原始参数随 `OutputFrame` 的 A / B 参考采样传递。当前没有真实设备协议适配，数据保留不等于已经验证硬件播放。

## 编辑与维护

默认波形不能删除或覆盖。复制时生成新 ID，保留全部采样参数，再允许编辑和删除。采样序列在编辑器中以 JSON 修改；自定义生成器仍可新建正弦、三角、脉冲、阶梯和插值曲线。波形没有描述字段。

应用离线读取内置数据，不登录原服务。更新默认库时只提交规范化波形数据及对应翻译；APK、提取源码、本地研究脚本、原始登录响应和凭据必须留在 Git 忽略的本地目录。已获授权的参考账号用 Windows DPAPI 当前用户密钥加密保存在本地，应用不读取该凭据。
