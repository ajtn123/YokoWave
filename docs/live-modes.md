# 音频与感应模板

这些功能均由普通节点组合完成，可编辑并保存为用户模板，使用统一后台会话与设备独占。图设置和实时设备读数分离，输入只在运行／校准时开启。

## 声控

音频节点支持本地 WAV／MP3／FLAC（最大 100 MiB）、默认麦克风和 Windows 默认播放设备的系统声音。Desktop 使用 SoundFlow／MiniAudio，Core 只消费每约 50 ms 的左右声道 RMS 与能量变化特征。音量／节奏跟随、灵敏度、噪声迟滞门和包络均在本地处理，dBFS 不表示环境声压或物理输出。

扬声器音量只影响媒体播放缓冲，不改变特征映射；0% 仍保持解码与分析。支持本地循环。环境校准采集约 2 秒，按较高分位估计底噪；只保存底噪参数。麦克风和系统输入不录音、不落盘、不上传。

静音、无回调、超过 2 秒的特征和媒体结束均归零等待，不结束会话、不反复打开输入；新帧恢复。实际输入错误停止图。暂停清空旧特征并暂停输入，停止／断连／关闭释放资源；停止也能取消尚未完成的输入启动。已开启的会话定时在等待期间继续生效。

## 禁锢与运动

禁锢模板为「传感器 → 基准偏差 → 范围映射 → 频率／脉宽映射 → 输出」。第一条有效读数建立该节点的基准，运行中可校准；默认安全角度 5°、渐增到 35°。每条链独立，可让多个传感器分别影响不同设备或通道。

运动模板为「传感器 → 运动计数 → 等待／输出周期 → 波形门控」。默认约 0.7 秒比较一次角度或步数变化，阈值可编辑；默认静止等待 10 秒、输出 5 秒，等待期间动作重置计时。可设置计数目标；多个目标计数节点均完成后才结束图。输入缺失／过期时等待，不把角度变化次数称为经过校准的步行步数。

传感器节点提供角度、计步、压力、按压、加速度／陀螺仪轴、按键、事件、电压和强度等数值端口；没有回报的字段保持缺失。真实协议流由资源参与者开启，停止时由控制器关闭。明确标识的模拟数值节点可替代输入测试，但模拟来源会沿处理链传播，不能驱动真实连接。

## 睡眠剥夺

固定模板默认等待 90 秒、输出 5 秒。随机模板每轮选择 30–90 秒等待、5–10 秒输出、50–100% 比例，并从本地波形池分别选择通道波形；范围与池均可编辑。活动重置模板在等待期间遇到动作后重新等待，需要新鲜输入。

周期、计数、波形与增益均为独立节点，可组合其他逻辑。暂停冻结活动时间；调度间隔超过 2 秒时重新等待，不补发错过的输出。所有路径经过相同上限、停止与日志处理。

自动测试使用输入及 GATT 替身，不打开真实麦克风或发送非零实机输出。macOS／Linux 提供媒体与麦克风后端，尚未在这些系统实机验证；系统声音目前限 Windows。
