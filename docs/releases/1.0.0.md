# YokoWave v1.0.0

首个便携发行版，提供 Windows、macOS、Linux 的 x64 / ARM64 包，内含 .NET 与 ASP.NET Core 运行时。

- 设备扫描、连接、自动重连和按能力显示的硬件选项；支持 YOKONEX 电击器 V1/V2、震动器、灌肠机，以及郊狼 V2/V3、负鼠、爪印 V1.1、灵猫。
- 节点图组合波形、触控、音频、传感器、计时、泵与原生程序；预设玩法均为普通图模板，可创建多个实例和子图模板。
- 66 条内置波形、统一波形格式、自定义播放列表和导入导出。
- WebSocket GATT、高层控制、触发／数值事件，及 DG-LAB V4 App 配对、被控节点和中继。
- 恐龙游戏静态包，碰撞时通过已有高层控制服务端触发有限输出。
- English / 简体中文，跟随系统字体、主题及可用强调色。

本次发行前的事件代码审查修复了重复捕获造成的重复触发／计数、过期触发占满队列、连接失败时的资源释放，以及离线事件目录持续积累。事件处理器和会话按捕获、去重、过期、租约、声明与发送拆分职责，共用现有管线和网络边界。

Windows 提供原生 BLE、媒体文件、麦克风和系统音频输入。macOS / Linux 支持本地模拟与远程设备，原生蓝牙尚未实现；其媒体和麦克风后端已实现，仍待平台实机验证。跨设备使用同一波形不表示物理输出等价。

完整解压后运行 Windows 的 `YokoWave.exe`、macOS 的 `YokoWave.app` 或 Linux 的 `./YokoWave`。保留目录内全部依赖。Windows / macOS 未使用开发者证书签名，macOS 为临时签名且未公证。操作说明在应用内「帮助」，平台与协议边界见仓库 README 和技术文档。
