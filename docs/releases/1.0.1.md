## 更新

- 默认设备来源改为蓝牙；保留已保存的来源选择，可在设置中切换本地模拟。
- 修复郊狼 V3 广播未携带名称时无法发现的问题，通过标准设备名服务识别；可选电量通知被拒绝时不再中断连接。
- 添加日本語、한국어界面、帮助及恐龙模块词典，支持系统语言识别与运行中切换；macOS 权限说明同步本地化。
- 所有本地化 JSON 按键统一排序，风格检查验证排序与格式。
- 升级 Avalonia 至 12.1.6。
- build / release 工作流不再测试或打包恐龙游戏；本版仅提供 Windows、macOS、Linux 的 x64 / ARM64 六个自包含桌面包。

Windows 支持原生蓝牙。macOS / Linux 当前使用模拟或远程设备；原生蓝牙尚未实现。
