# 电刺激与波形操作

本地及远程输出均通过 `PipelineSession → DeviceController → IDeviceTransport` 执行。波形、滑动、声控、感应、泵与原生程序均是节点图模板；创建后可以调整、添加或删除节点，不受固定玩法类型约束。完整操作见 [节点玩法](pipelines.md)。

## 波形与播放列表

每个播放列表节点独立选择波形、资产通道、相位、播放顺序与最多 100 条列表。支持重复、单次、顺序和随机；随机在有其他选项时避免连续重复。模板的 B 通道默认错开半周期，可直接修改相位或选择独立波形。C 通道也可独立连线。

运行中选择新波形从起点播放，只重置该节点的波形相位，不重置图时钟、强度或期限。顺序／随机只能切换到本列表内资产，列表本身运行期锁定。所有单次完成节点均完成后结束；较早完成的节点先归零。暂停关闭输出、保留位置和占用，继续后只计算活动时间。

24 条内置波形与自定义波形使用统一格式，在发送时由设备驱动转换；默认波形不能删除，编辑默认波形会创建副本。波形库保留参数、预览、导入导出及自定义编辑。图或模板引用的波形不能删除。

## 强度与硬件

常量或其他数值输入提供每通道的基础比例，强度进度节点提供固定、随机增加、按间隔递增与按住增强。0 不会因进度或增强自动开启；重置清除自动增量和计时。强度节点后接增益，与波形或输入特征组合。强度上限保存在各输出／控制节点中，逐帧独立生效并支持运行中调整；一个通道的上限不会影响其他通道。

按住增强支持指针、Space 和 Enter，松开、失焦、失去捕获或离开编辑器时解除。温柔模式、辅助马达、硬件通道上限、DG 平衡与相对强度由输出节点配置。同一设备输出节点的硬件选项须一致，协议能力决定可用性。

原生程序支持电击固定预设、二代频率／脉宽缓冲序列与循环开关、马达固定预设，以及郊狼 V2 原始 X/Y/Z。马达固定预设只有开关能力，通道必须为 0 或 100%，该原生输出节点的上限必须为 100%；可调强度使用普通波形输出。

## 设备、停止与保存

图拥有配置；设备只保存连接和实时读数。一个实例可控制多设备，同一设备运行及暂停期间仅由一个实例占用。选择页面或其他实例不会结束会话。停止、Escape、全部停止、切换本地传输、断连与关闭均使用统一停止流程，无法确认停止的设备保持占用。

设备页保留电量、接触、固件与灯光，以及所有已实现协议命令。接触读数显示开关位于设置。启动与重连均不恢复非零输出。图、模板、波形、全局设置与会话日志分别保存，见 [架构](architecture.md)。
