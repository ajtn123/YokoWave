# 离线电刺激控制

本地控制通过 `SessionEngine → DeviceController → IDeviceTransport` 执行，不访问登录、房间、远程控制、在线分享或音频上传分析接口。Windows 可连接已支持的电击器；其他平台可使用模拟传输。

## 波形与暂停

- 默认 A/B 共用波形，B 可错开半周期。勾选「独立设置 B 通道波形」后，两路分别采样，预览也分别显示；独立波形不再使用共用波形的半周期错相。
- 单曲循环、仅播放当前、顺序循环和随机循环均使用本地波形。顺序和随机播放在当前波形完成后切换到同类设备波形；随机模式在存在其他波形时避免连续重复同一条。两路独立播放时分别推进。
- 「仅播放当前」在两路完成后结束会话；较早完成的通道先归零。其他模式仍遵循会话定时。
- 运行中可分别切换 A/B 波形，新波形从起点播放，不重置会话期限、目标设备或强度。
- 暂停立即发送关闭输出指令，并停止活动时钟。继续后保留波形位置与剩余时长。停止、页面切换和断连仍按原有规则处理。

## 强度

工作台展开「自动强度与临时增量」配置：

| 模式 | 行为 |
| --- | --- |
| 固定强度 | 使用 A/B 滑块的基准强度 |
| 随机增加 | 每隔指定秒数，在基准上增加不超过指定范围的随机值；一个间隔内保持该值 |
| 递增强度 | 每隔指定秒数增加一步，直到递增目标；低于基准的目标不会降低基准 |
| 临时增量 | 按住时增加，松开、失去焦点或失去指针捕获后恢复当前自动强度 |

0% 的通道不会因自动变化或临时增量而被激活。每台设备的输出上限在最终发送入口再次裁剪，因此联动设备仍保留各自上限。「重置自动增量」返回基准强度并重新计算变化间隔。模式参数在会话中锁定。

偏好设置的「温柔模式」保持界面百分比，在编码时使用较低的设备强度：满量程为 180 个协议等级，普通模式为 276 个等级；0 始终编码为关闭。两代设备均支持。这些数值不表示校准电流。

## 滑动控制

开始前开启「滑动控制」，再开始会话并按住拖动面板。横轴为频率参数 1–100，纵轴为脉宽参数 0–100；强度仍由 A/B 滑块、自动强度与设备上限共同决定。

| 松手模式 | 行为 |
| --- | --- |
| 按住输出，松手归零 | 松开即发送零输出；会话与定时继续 |
| 循环回放轨迹 | 松开后循环本次按住期间采集的参数 |
| 保持最后参数 | 松开后继续最后的频率、脉宽，直到停止 |

再次按下会替换上一条轨迹。轨迹每 100 ms 采集一次，最多 256 帧（25.6 秒）；到达上限后仍可实时控制，但不再追加记录。停止后，填写名称可将至少两帧的轨迹保存为自定义电击波形，随后可使用现有 JSON 导入导出功能。不会生成或替换系统默认波形。

## 设备状态与灯光

「显示电极接触状态」只影响界面，不修改设备检测或输出行为。

二代设备连接后可点击「读取设备信息」，读取硬件、固件版本与灯光状态。只有兼容版本和灯光状态均被确认后，灯光操作才可用；无回复或回复无效时保持不可用，不推测成功。灯光操作在会话停止时进行，必须收到设备状态确认。

会话记录保存结束时的 A/B 波形、是否使用滑动控制和温柔模式。活动时间不包含暂停时间；日志仍遵循 128 KiB、一个旧文件的滚动规则。

## 当前边界

未加入依赖服务端的账号、房间、远控、共享作品、任务或上传分析功能。APK 中的实时麦克风和角度感应需要额外的平台采集与硬件状态验证，目前没有在桌面端提供；也不把手机或其他玩具的传感器数据模拟为已验证的电击器读数。

新增功能通过模拟传输和 GATT 替身验证；本次开发未发送非零实机输出，固件灯光功能尚待对应实机确认。
