# 离线电刺激控制

本地控制通过 `SessionEngine → DeviceController → IDeviceTransport` 执行，不访问登录、房间、远程控制、在线分享或音频上传分析接口。Windows 可连接已支持的电击器；其他平台可使用模拟传输。

## 玩法预设与目标设备

左侧类型选择器可创建波形、滑动、声控、禁锢、运动、睡眠剥夺、泵控制或设备原生程序实例；命名并选中分组，将未分配设备加入当前玩法，设备随即显示在该玩法卡片内。每类可以创建多个实例，创建后类型固定。设备在停止时也只归属一个玩法，改派前先从原玩法移除；蓝牙连接与分配玩法是独立操作。全部玩法参数归实例所有，设备不保存配置。最多保存 32 个玩法，紧凑写入独立的 `modes.json`；全局设置只保存语言、设备来源、新玩法默认上限与定时滑块最大时长。

各玩法可独立运行或暂停。一个玩法可以控制多台设备，同一设备不能同时被两个运行中的玩法占用，暂停仍保留占用。停止或断连仅影响所属玩法及其全部目标；切换页面、查看设备或选择其他玩法保留已有会话。切换玩法时清除临时按住状态。「全部停止」、Esc、切换设备来源与关闭应用停止所有玩法。启动应用只恢复预设，不自动连接或开始输出。

## 波形与暂停

- 单曲循环与仅播放当前默认 A/B 共用波形，B 可错开半周期。勾选「独立设置 B 通道波形」后，两路分别采样，预览也分别显示；独立波形不再使用共用波形的半周期错相。
- 波形玩法提供自定义有序列表，最多 100 个不同波形。可添加、移除、上下排序，列表随所属玩法保存。顺序和随机播放只使用此列表，从首项开始，A/B 共用列表曲线；随机模式在存在其他波形时避免连续重复同一条，不自动遍历整个波形库。列表可混合所有来源的统一波形，播放时按设备协议转换。列表在运行期间锁定，空列表拒绝开始顺序或随机播放。
- 「仅播放当前」在两路完成后结束会话；较早完成的通道先归零。其他模式仍遵循会话定时。
- 运行中切换波形时，新波形从起点播放，不重置会话期限、目标设备或强度；列表模式只能切换到本列表内的波形，单曲与仅播放当前支持分别切换 A/B。
- 暂停立即关闭本玩法目标的输出，并停止自身活动时钟。继续后保留波形位置与剩余时长，其他玩法不受影响。

## 强度

工作台展开「自动强度与临时增量」配置：

| 模式 | 行为 |
| --- | --- |
| 固定强度 | 使用 A/B 滑块的基准强度 |
| 随机增加 | 每隔指定秒数，在基准上增加不超过指定范围的随机值；一个间隔内保持该值 |
| 递增强度 | 每隔指定秒数增加一步，直到递增目标；低于基准的目标不会降低基准 |
| 临时增量 | 按住时增加，松开、失去焦点或失去指针捕获后恢复当前自动强度 |

0% 的通道不会因自动变化或临时增量而被激活。玩法引擎在计算自动与临时增量后，按玩法上限裁剪最终输出；该玩法所有目标使用同一上限。「重置自动增量」返回基准强度并重新计算变化间隔。播放与自动强度策略在启动及运行期间锁定，基础强度和输出上限可实时调整。

玩法高级控制中的「温柔模式」保持界面百分比，在编码时使用较低的设备强度：满量程为 180 个协议等级，普通模式为 276 个等级；0 始终编码为关闭。两代设备均支持。这些数值不表示校准电流。

## 滑动控制

添加滑动玩法，分配并连接设备后开始会话，按住拖动专属面板。滑动实例不显示波形选择或播放列表；横轴为频率参数 1–100，纵轴为脉宽参数 0–100，强度由该玩法的 A/B 滑块、自动强度与输出上限决定。

| 松手模式 | 行为 |
| --- | --- |
| 按住输出，松手归零 | 松开即发送零输出；会话与定时继续 |
| 循环回放轨迹 | 松开后循环本次按住期间采集的参数 |
| 保持最后参数 | 松开后继续最后的频率、脉宽，直到停止 |

再次按下会替换上一条轨迹。轨迹每 100 ms 采集一次，最多 256 帧（25.6 秒）；到达上限后仍可实时控制，但不再追加记录。停止后，填写名称可将至少两帧的轨迹保存为自定义电击波形，随后可使用现有 JSON 导入导出功能。不会生成或替换系统默认波形。

## 设备状态与灯光

「显示电极接触状态」只影响界面，不修改设备检测或输出行为。

二代设备连接后可点击「读取设备信息」，读取硬件、固件版本与灯光状态。只有兼容版本和灯光状态均被确认后，灯光操作才可用；无回复或回复无效时保持不可用，不推测成功。灯光操作在会话停止时进行，必须收到设备状态确认。

会话记录保存玩法 ID 与名称、结束时的 A/B 波形、是否使用滑动控制和温柔模式。活动时间不包含暂停时间；日志仍遵循 128 KiB、一个旧文件的滚动规则。其他玩法运行中使用的波形不能编辑或删除，停止占用玩法后才可修改。

## 当前边界

未加入依赖服务端的账号、房间、远控、共享作品、任务或上传分析功能。声控、禁锢、运动与睡眠剥夺已作为独立离线实例实现，输入来源、规则、平台限制及验证范围见 [声控与感应玩法](live-modes.md)。不会把模拟角度或其他玩具的传感器读数冒充真实电击器读数。

功能均通过模拟传输和 GATT 替身验证；固件灯光功能尚待对应实机确认。

## 设备原生程序与协议控制

设备原生程序由独立玩法保存，各实例可选择固定电击程序、二代频率序列、固定马达程序或郊狼 V2 原始脉冲，按设备能力分配目标。固定马达程序没有协议强度限幅，只提供通道开关。辅助马达与 V3 硬件上限／相对更新由玩法硬件选项保存；传感器与状态查询使用实体设备的协议控制面板。完整字段、停止行为和功能边界见 [蓝牙设备接入](bluetooth.md)。
